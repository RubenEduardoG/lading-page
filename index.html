Cómo vamos a trabajar

La idea es avanzar de forma simple: primero se define visualmente cada página y luego se realiza el desarrollo sobre una propuesta ya validada.

1

Template inicial

Se presenta una propuesta visual para que pueda verse anticipadamente cómo podría quedar cada landing.

2

Revisión

Se revisan textos, colores, imágenes, secciones y cualquier detalle que sea necesario ajustar antes de avanzar.

3

Desarrollo

Con la propuesta visual definida, se desarrolla la versión funcional y responsive de ambas páginas.

4

Entrega final

Se realizan las pruebas finales y se entregan las dos landing pages listas para utilizar.

El plazo estimado comienza una vez definidos los contenidos principales y recibidos los materiales necesarios para trabajar, como textos, imágenes, logotipos, datos de contacto y cualquier otro recurso que deba incluirse.

Qué incluye cada landing

Diseño responsive

Adaptación visual para celulares, tablets, notebooks y pantallas de escritorio.

  • Antes del desarrollo final se presentará un template o propuesta visual para revisión.

Publicación, hosting y mantenimiento

El valor de desarrollo corresponde a la creación y entrega de las dos landing pages. La publicación y el alojamiento en Internet no forman parte del valor de USD 300.

Si la clienta desea que también nos ocupemos de mantener las páginas online, ofrecemos un servicio opcional de hosting, despliegue y mantenimiento por USD 25 mensuales.

La web se entrega como producto

Los USD 300 corresponden al diseño y desarrollo de las dos landing pages. Una vez finalizadas, las páginas quedan entregadas como el producto contratado.

Publicación opcional

La publicación en Internet es un servicio adicional. Si se contrata, nosotros realizamos el despliegue y mantenemos las páginas en infraestructura administrada por nosotros.

Dominio a elección

Las páginas pueden utilizar el dominio que la clienta elija, apuntándolo hacia nuestra infraestructura. El registro o renovación del dominio no está incluido salvo que se acuerde expresamente.

No incluye despliegue en servidores de terceros

El servicio mensual contempla alojamiento y despliegue únicamente en servidores administrados por nosotros. La instalación o configuración en servidores, hostings o cuentas de terceros no está incluida en esta propuesta.

Qué incluye el abono mensual

Hosting, publicación, mantenimiento técnico, disponibilidad del sitio y resolución de inconvenientes vinculados al funcionamiento de las páginas alojadas en nuestra infraestructura.

Backend y almacenamiento de datos

Si se necesita guardar información enviada por usuarios, administrar formularios, clientes, reservas, registros u otros datos, será necesario incorporar backend, base de datos y una infraestructura adecuada. Ese desarrollo se cotiza por separado.

Futuras ampliaciones

Si más adelante se desea ampliar las páginas, desarrollar una aplicación, incorporar un panel administrativo, pagos, reservas, automatizaciones u otras funcionalidades, se coordinará una reunión para definir el nuevo alcance y se enviará un presupuesto independiente para su aprobación antes de comenzar.

Qué no está incluido

La propuesta corresponde al diseño y desarrollo de dos landing pages. Los siguientes servicios no se consideran incluidos salvo acuerdo adicional.

Sistemas o paneles administrativos

Desarrollo de sistemas internos, paneles de gestión, usuarios registrados o áreas privadas.

Tiendas online

Carrito de compras, medios de pago, catálogo administrable o funcionalidades de comercio electrónico.

Despliegue en infraestructura de terceros

La configuración, instalación o mantenimiento de las páginas en servidores, hostings o cuentas externas del cliente o de terceros no está incluida.

Integraciones especiales

APIs externas, CRMs, automatizaciones, pasarelas de pago, sistemas de reservas u otras integraciones personalizadas.

Producción de contenido

Fotografía profesional, producción audiovisual, redacción extensa, campañas publicitarias o gestión de redes sociales.
